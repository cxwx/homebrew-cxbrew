# Archived formulae

Formulae here are still installable (`brew install cxwx/cxbrew/<name>`) but are
no longer maintained or updated.

- Skipped by the Livecheck auto-bump workflow (`.github/workflows/livecheck.yml`).
- Skipped by the full regression workflow.

Fully retired (uninstallable) formulae live in `Formula.removed/` instead,
which is outside brew's `Formula/` scan path.
